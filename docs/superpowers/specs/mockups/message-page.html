M1 · Tree table with a detail panel (recommended)

One dense, scannable table — the whole structure of a message on one screen, like the workbook vendors know, but collapsible. Clicking a row opens its full definition on the right, with the XML it produces and every message that uses the same field. Tabs hold the sample message, conditions, XSD and changes.

M2 · Definition blocks

Every field as a readable block with its description in full, groups as headings, an outline on the right. Easier for a first read, but P001 has ~110 rows: the structure no longer fits on a screen and comparing fields means scrolling.
